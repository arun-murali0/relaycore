# RelayCore

A multi-tenant **webhook delivery service** with a web dashboard. Your backend sends an event to RelayCore; RelayCore delivers it to each customer's webhook URL: **signed, retried, rate limited, observable and fully tracked**, without ever making your request wait on a customer's server.

**Stack:** Node.js · TypeScript · Express · MongoDB (Mongoose) · Redis · BullMQ · pino · Prometheus · Vitest · React · Vite · Tailwind · TanStack Query · pnpm · GitHub Actions · Docker
